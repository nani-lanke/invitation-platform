# Project Guidelines & Workflow Rules

- Inspect only files relevant to the current task.
- Read large files in smaller sections.
- Avoid repeated file reads and unnecessary full-project scans.
- Keep terminal output concise.
- Use targeted edits instead of rewriting entire files.
- Preserve existing UI, working code, and functionality unless explicitly asked to change them.
- Test only the relevant functionality first.
- Perform broader validation when necessary.
- At the end of each task, report changed files, completed changes, and verification results.
